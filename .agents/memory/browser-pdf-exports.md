name: Browser PDF exports
description: Reliable PDF generation and report structure for Vendor Compare.
---

Generate downloadable reports directly with PDF primitives instead of rasterizing hidden HTML. Keep the C-suite summary to the first page and paginate detailed analysis dynamically afterward.

**Why:** Hidden DOM capture was browser-sensitive and caused downloads to fail. Fixed-height screenshots also clipped long equivalency, gap, governance, migration, and source content.

**How to apply:** Build page one as a concise executive decision summary with vector score graphics. Add dynamically paginated appendices for assumptions, equivalency, gaps, service/product mapping, migration, governance, and all evidence sources.
