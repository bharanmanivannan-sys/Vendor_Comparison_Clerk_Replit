---
name: Model URL provenance
description: Rules for preventing model-invented URLs from entering comparison evidence.
---

Model-authored URL strings in prose or structured JSON are untrusted claims, not retrieval provenance. A URL is eligible for comparison evidence only when it is explicitly supplied by the customer, generated by a deterministic official-source rule, or attached to an explicit web-search/retrieval citation result.

**Why:** A syntactically valid or publicly reachable URL can still be invented by the model and unrelated to the researched claim, especially when a bank page is unavailable or access-restricted.

**How to apply:** Keep model source fields descriptive only. Build the candidate source set from approved origins, validate availability and permission separately, and remove unapproved URLs from persisted evidence and report-facing citation fields.
