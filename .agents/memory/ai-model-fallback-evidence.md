---
name: AI model fallback evidence
description: Rules for qualifying and scoring exact AI models when primary launch pages are inaccessible.
---

Use deterministic public provider-developer documentation as fallback evidence only after the normal publisher-permission, robots, retrieval, hashing, and citation checks. Treat current API availability as a separate claim supported by an official exact model ID or available-alias statement; pricing or context evidence alone must not pass availability. Bind prices, context windows, and benchmarks to the nearest exact model section or row, never merely to the page URL. Benchmark comparisons require the same named benchmark, version, task, configuration, and scale.

**Why:** Provider pages often contain several neighboring models, and generic pricing tables can otherwise transfer a value to the wrong model. Historical pricing also does not prove a model remains available.

**How to apply:** For AI-model comparisons, preserve exact decimal model versions, keep blocked or prohibited sources non-scorable, and allow a unique leader to qualify normally only after exact identity, current availability, and comparable metric provenance all pass.
