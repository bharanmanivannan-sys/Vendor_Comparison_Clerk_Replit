---
name: White-label delivery
description: Defines the chosen white-label product boundary and security model.
---

White-label support is API-only. Customer developers build and operate their own branded web, mobile, agent, or automation experience; this project supplies presentation-neutral structured comparison data.

**Why:** The user explicitly selected the API-only model instead of an embeddable widget or fully hosted branded portal. Keeping the key behind the customer's backend also prevents credential exposure.

**How to apply:** Keep customer-facing branding and presentation out of API responses. Document server-side bearer-key calls, allow customers to select and transform response fields, and preserve evidence, assumptions, warnings, and traceability.
